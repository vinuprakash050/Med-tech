# Frontend (React)

Lightweight React UI for the Medicine Alternative Recommendation backend.

## Setup

From the project root:

```bash
cd frontend
npm install
npm run dev
```

The app expects the backend at `http://127.0.0.1:8000` by default. To change, set `VITE_API_BASE` in your environment or in a `.env` file in this folder (e.g. `VITE_API_BASE=http://127.0.0.1:8000`).

Open the site at the address printed by Vite (usually `http://localhost:5173`).
